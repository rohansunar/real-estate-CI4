Mobile Menu Test Page

This page tests the mobile menu functionality in isolation.

Instructions:

  1. Resize your browser window to less than 992px width (or use mobile device)
  2. You should see a hamburger menu button (3 lines) in the top navigation
  3. Click the hamburger button to open the mobile menu
  4. The menu should slide in from the left
  5. Click the X button or overlay to close the menu
